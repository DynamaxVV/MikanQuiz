# 从漫画图片批量制题

在题库页或新增题目页点击「批量制题」，新建一个批次，拖入或选择多张 JPG、PNG、WebP 图片。文件名按自然顺序排列，可以继续追加页面。

## 连续操作

1. 在漫画上拖出一个矩形，右侧显示题目编辑表单；整页漫画保留在中间画布中查看。画布工具栏居中，左侧缩略图超出高度后滚动。
2. 选择难度、正确字体，填写解析。题干默认沿用现有题干，可展开修改。
3. 点击「完成并继续」或按 Ctrl/Cmd+Enter，接着框选下一处。
4. 不确定的题目点「暂留待补」。一页处理完可标记「此页已检查」。

点击漫画上已有区域可继续编辑。选中后可拖动、拉动四角调整；画布获得焦点时方向键按原图 1 像素微调，Shift+方向键为 10 像素，空格拖动画布，Esc 取消当前框选。

答案不会默认复制上一题。选择已有字体时，当前批次上一个同字体且已有解析的题目会显示临时建议，按 Tab 才会采用；手动输入会清除建议。调整题图或内容后，已完成题目会重新变成待补充，需要再次确认。高于当前难度的字体不可选；题目难度下降时，旧答案需要重新检查。

## 检查与分次入库

点击右上角「检查并入库」，勾选本次需要入库的题目。检查页按答题端样式显示题干、题图、选项和解析；需要调整时通过每题的「编辑区域」返回框选。未完成题目不会提交；成功入库的题目即可参与现有出题流程。

提交队列逐题上传裁图并创建题目，可以暂停后续项。上传失败可重试；图片已上传时复用 URL。创建题目后响应丢失时，重试同一提交标识，服务器返回已有题目，不重复创建。

「待确认提交」项会锁定内容，需先重试确认结果。登录过期时，在新标签页登录同一管理员，再回来重试。已入库区域只读，点击「题库编辑」修改正式题目。

裁图按原图像素导出 PNG；超过现有 8 MB 上传限制时提示缩小区域，不静默缩小文字图像。

## 本机草稿

原图和草稿仅保存在当前网站、当前浏览器的 IndexedDB 中，按管理员账号分开。同一批次只允许一个标签页编辑。刷新或关闭浏览器后，从批次列表继续。

- 只有存储事务成功才显示「已保存到本机」。保存失败时保持页面打开，释放存储空间后点击重试。
- 清除网站数据、使用无痕窗口或换浏览器会影响本机草稿；这不是服务器备份。
- 删除本机批次会删除其原图与草稿，不会删除正式题目。
- 原图不上传服务器，正式入库只上传裁图。首版不提供跨设备续做、自动识别、拼图或 PDF/ZIP 导入。

## 接口与迁移

`POST /api/v1/admin/questions` 新增可选 `client_request_id`，原有调用不变。标识为 1–64 位字母、数字、下划线或连字符；前端采用 UUID。服务器按管理员与标识建立唯一回执，回执与题目同事务提交。

- 相同标识、相同规范化内容：返回已创建题目，HTTP 201。
- 相同标识、不同内容：HTTP 409，`QUESTION_REQUEST_CONFLICT`。
- 原题已被删除：HTTP 409，`QUESTION_REQUEST_DELETED`，不重新创建。
- 请求校验或事务失败不会保留占用标识。

新迁移：`20260909_0012_question_requests`。部署后端前，在目标环境按既有部署流程备份数据库，并从 `web/backend` 执行 `.venv/bin/alembic upgrade head`。本次实现不执行服务器迁移或部署。

## 可重复验证

后端使用 pytest 临时数据库和 Alembic：

```sh
cd web/backend
.venv/bin/python -m pytest tests -q
```

前端基础检查需要支持 TypeScript 类型剥离的 Node.js 22.18+：

```sh
cd web/frontend
npm run test:batch-core
npm run build
```

浏览器测试需要独立可用的 Playwright 及 Chromium（不加入产品依赖），并启动本地 Vite：

```sh
cd web/frontend
npm run dev -- --host 127.0.0.1 --port 5178 --strictPort
# 另一个终端，已有 Playwright 可直接解析时：
npm run test:batch-browser
```

Playwright 位于外部工具目录时用 `NODE_PATH` 指向其 `node_modules`；可用 `BATCH_BROWSER_EXECUTABLE` 指定已安装的 Chromium。`BATCH_TEST_URL` 默认 `http://127.0.0.1:5178`，截图默认写入 `/tmp/mikanquiz-batch-check`，可用 `BATCH_TEST_OUTPUT` 更改。

测试拦截全部 `/api/v1` 请求，使用浏览器生成的合成图片，不接入真实服务器或 R2。覆盖导入排序、缩放坐标、裁图像素、区域微调与调整、刷新恢复、多标签页锁、分次提交、上传失败、创建成功但响应丢失、登录过期以及存储失败恢复。另以 36 页、108 个合成区域验证本地存储和账号隔离，作为快速回归基线。

真实性验收边界：合成浏览器测试与后端 API 测试不替代真实内容验收；生产部署、目标域名和 R2 仍需单独验证。

现有 `npm run test:api-contract` 中对 `QuizPage.vue` 的 `moveAnswer` 断言与当前答题页不匹配；本功能未修改该答题页或该旧断言，需作为既有检查缺口单独处理。
