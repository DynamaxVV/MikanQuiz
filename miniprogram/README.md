# 历史微信小程序（停止维护）

本目录仅保留为历史实现参考。当前产品与所有新增功能、修复、UI 和发布均以 `web/` 为准；旧客户端不属于 Web 构建、部署或验收范围，也不承诺与当前后端持续兼容。

- 根目录 `project.config.json` 保留为微信开发者工具配置；未使用的跨平台配置与脚手架已清理。
- `config/api.js` 使用示例 API 地址；根目录项目配置使用示例 AppID，均不能直接作为线上配置。
- 个人开发者工具配置与本地凭据不得提交。只有明确调查历史行为时才配置和运行旧客户端。
- `npm run check` 仅检查旧客户端 API 调用约定，不代表当前产品验收通过。

当前安装和使用方式见 [项目 README](../README.md)。
